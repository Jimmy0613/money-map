## 점검 범위와 근거

루트 Markdown 15개(요구사항·아키텍처·ERD·API·변경 기록·인계·실행 보고 포함)를 다시 읽고 관련 소스와 기존 테스트 assertion/로그/XML을 대조했다. frontend/AGENTS.md와 CLAUDE.md도 확인했다. 신규 실행 테스트나 운영 배포를 수행한 점검은 아니다. 현재 문서의 사본은 `evidence/review-2026-09-23/`, 정적 점검 결과는 `evidence/self-review-2026-09-23.json`에 보존했다. 전달 15개 존재 및 DOCX6개 원본 해시 일치를 재확인했다. Secret 파일과 사용자 DB는 열지 않았다.

## 현재 판정

- 핵심 기능은 구현되어 있고 실제 PostgreSQL·Kakao·HTTPS 검증 증거가 있다.
- Galaxy S25 / Android16 / Chrome153.0.8010.52에서 위치 허용→주소 저장→Marker 상세, 위치 거부→위치 없는 저장을 사용자가 확인했다. 이는 사용자 수동 확인이며 자동화 기록과 구별한다.
- 기존 Backend XML: 단위/HTTP34, DB통합11, 부하1, 각 실패0. Frontend 최신 부분 회귀26PASS. HTTP E2E2개와 Kakao1개는 localhost/HTTPS 실행 이력을 구별한다. 서로 다른 시점의 통과를 최신 코드 전체 재실행으로 합산하지 않는다.
- 추적표는 **71개 테스트 사례 중26PASS/45NOT_RUN**, 요구사항 ID는43개다. 26개 요구사항 완료 또는 기능45개 미구현이라는 뜻이 아니다. FR-027 두 사례는 승인된 Could 제외 범위다.
- iOS 실기기 없음, 최신2개 주요 버전 전수 미확인. 운영 서버·백업 환경 미선정, 비용은 무료만 허용. 외부 준비와 관계없이 가능한 로컬 보완이 남아 있다.

## 문서·추적 방식의 문제와 이번 정정

1. 전달 당시 Windows 미실행,9월19일 실행,9월21~23일 외부/수동 확인이 누적되어 상단의 현재 상태와 충돌했다. 현재 상태를 먼저 표시하고 과거 문구는 이력으로 식별한다. 승인 요구사항 본문과 과거 증거는 유지한다.
2. README의8개 DB통합·25PASS/46NOT_RUN 등 과거 수치가 최신처럼 보였다. 현재26/45와 DB11을 명시한다. 과거 실행 수치는 당시 이력으로 보존한다.
3. TC-FR-018-01/019-02/028-01 등은 다른 테스트의 조건까지 Note에 섞여 상위 NOT_RUN의 이유가 불명확하다. 기대값을 바꾸거나 자동 PASS로 올리지 않고 다음 회귀에서 각 assertion과 Test ID를 직접 매핑한다.
4. FR-023-02의55/10/34 비율, FR-026-02의262.5%, FR-018-01의반전 위도 등 이미 검증된 일부 조건이 미실행이라고 남아 있었다. 기존 assertion과 일치하게 설명을 정정하되 아직 부족한 조건은 유지한다.
5. NFR-003 원 요구사항에는 변경 API 성능도 포함되지만 현재 성능 이력은 조회7개 경로다. 추적표에 계획된 조회 부하 PASS가 NFR-003 전체 완료를 뜻하지 않도록 명시한다. NFR-013도 서버 로그 검증 PASS와 SDK 오류 집계 누락을 구별한다.
6. 원래71개 계획만으로 요구사항 전체가 완전히 검증되지는 않는다. 가입3분/재방문 등록30초, 변경 API p95, 화면 전체44px/스크린리더, 외부 오류 집계 등의 추가 추적이 필요하다. 기존 Test ID/기대값은 유지하고 하위 검증으로 추가한다.
