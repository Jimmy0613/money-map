# 지역 자료 검증

2026-09-18 [행정표준코드관리시스템 법정동코드](https://www.code.go.kr/stdcode/regCodeL.do)의 전체자료 다운로드를 실제 수행했다. 다운로드 파일은 ZIP, 본문 CP949 TSV이며 코드/명칭/폐지여부 3열이다. 총 53,387행, 시군구 수준 코드(뒤 5자리 0, 시도만 나타내는 코드 제외) 512행, 현존 269행을 확인했다. 원문과 SHA-256은 evidence/official-region-download.bin 및 region-source-metadata.json에 보존한다. 자료의 발행일이 명시되어 있지 않아 **수집일**을 버전 `code.go.kr-2026-09-18`로 사용하며 발행 기준일이라고 주장하지 않는다.

V5는 512개의 코드 사전을 추가한다. 폐지 코드도 과거 거래 식별을 위해 보존하고, 현존 이름 269개만 수집일부터 유효한 별칭으로 추가한다. 이 스냅샷에는 생성·폐지일이 없으므로 과거 별칭의 유효 기간을 추정하지 않는다. 수집일 이전 거래에서 코드 없는 이름만 주어진 경우 UNKNOWN으로 남을 수 있다. 추가 공인 이력 자료를 확보하면 새 Migration으로 기간을 보완한다. 실제 지역 통계의 과거 이름 정규화 검증은 미완료다.

특수 구역 검토:

- 세종은 36110, 이름 `세종특별자치시`, 하위 시군구명 빈 문자열. 코드로 식별 가능하다.
- 제주특별자치도 제주시 50110, 서귀포시 50130, 과거 제주도 코드도 별도로 보존한다.
- 수원시/청주시 등 일반구가 있는 도시는 상위 시와 구의 서로 다른 앞 5자리를 보존한다. 주소의 첫 단어만 잘라 시 이름에 강제 병합하지 않는다.
- 대구광역시 군위군 27720(현존), 경상북도 군위군 47720(폐지)을 확인했다.
- 강원특별자치도 51 및 전북특별자치도 52 코드 확인. 과거 코드와 자동 병합하거나 과거 거래 스냅샷을 갱신하지 않는다.

테스트 F0용 최소 지역 사전은 테스트 환경에서만 생성한다. 공식 자료에 합성 이름이나 코드가 섞이지 않는다. 실제 Kakao B 응답과 특수 구역의 주소 일치 확인은 공개키가 없어 NOT_RUN이다. 2026-09-19 Docker 설치 후 V1~V5 Migration/JPA validate 및 교차 사용자 FK 거부는 실제 PostgreSQL Testcontainers에서 PASS했다.
