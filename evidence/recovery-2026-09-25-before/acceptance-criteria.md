## 위치 화면 상태 결정

- 미선택: 위치 없음 안내, 사용자 행동 전에는 GPS/지도 미리보기 자동 요청 안 함.
- 선택 중: 선택 좌표의 출처·주소/좌표·미리보기·확정/취소를 제공.
- 확정/기존 거래 수정: 출처·주소/좌표·제거를 표시. 지도 확인 버튼으로 해당 저장 대상 좌표를 검토하며 새로운 위치를 자동 수집하지 않음.
- 지도 실패: 텍스트 확인·제거·위치 없는 저장 유지.

지도 상시 노출은 승인된 필수 레이아웃으로 간주하지 않는다. 명시적 확인 동작으로 FR-016의 확인 목적을 충족하도록 결정했다.

## 판정 원칙

하위 검사 PASS를 상위 요구사항 전체 완료로 자동 승격하지 않는다. Mock UI/API 연결, 실제 DB, 실제 SDK·기기, 운영 환경의 증거를 별도로 적는다. 이번 실행은 Frontend55PASS, 타입/lint/독립 생산 빌드와 Mock E2E 검사이며 Backend·운영 복원·실기기를 새로 실행했다고 간주하지 않는다. 복원 증거 없을 때 자동 차단하는 제어 계층은 설계만으로 완료 처리하지 않는다.
